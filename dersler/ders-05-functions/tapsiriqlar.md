## JavaScript Funksiyaları — Praktik və Nəzəri Tapşırıqlar

**Tapşırıq 1:** Bir funksiya yaradın, çağırıldıqda konsolda `"JavaScript funksiyaları mövzusunu öyrənirəm!"` yazısını göstərsin.

**Tapşırıq 2:** `ugurMesaji` adlı bir funksiya yaradın. Bu funksiya ekrana `"Kod uğurla işlədi!"` yazısını çıxarsın və funksiyanı 3 dəfə ardıcıl çağırın.

**Tapşırıq 3:** Konsola `"Xoş gəldiniz!"` yazdıran bir funksiya yaradın. Bu funksiyanı həm yaradılmasından  **əvvəl** , həm də **sonra** çağırmağa çalışın

**Tapşırıq 4:** Boş bir funksiya yaradın (daxilində heç bir kod olmasın). Bu funksiyanı çağırıb nəticəsini bir dəyişənə mənimsədin və həmin dəyişəni konsola çıxarın. Ekranda nə görəcəksiniz?

**Tapşırıq 5:** `toplama` adlı funksiya yaradın. Funksiya iki parametr qəbul etsin və daxilində bu iki parametrin cəmini konsola çıxarın.

**Tapşırıq 6:** `salamla` funksiyası yazın. Bu funksiya `ad` parametri qəbul etməlidir. Əgər funksiya çağırılanda heç bir ad ötürülməzsə, ekrana `"Salam, İstifadəçi!"` yazılmalıdır (yəni defolt dəyər `"İstifadəçi"` olmalıdır).

**Tapşırıq 7:** `vurma` adlı funksiya yaradın. İki parametr qəbul etsin (`a` və `b`). `b` parametrinə defolt olaraq 1 dəyərini verin. Funksiya bu ədədlərin hasilini konsola yazdırsın.

**Tapşırıq 8:** `profilYarat` adlı funksiya yaradın. Parametr olaraq `ad` və `rol` qəbul etsin. `rol` parametri üçün defolt dəyər `"Qonaq"` olsun. Funksiya `"İstifadəçi: [ad], Rol: [rol]"` formatında mesaj yazdırsın.

**Tapşırıq 9:** Bir funksiyaya təyin olunandan daha çox arqument (arqument sayı > parametr sayı) ötürsək nə baş verər? Kod yazaraq yoxlayın və izah edin.

**Tapşırıq 10:** Funksiya yaradın, `return` ilə hər hansı bir string dəyər qaytarsın. Funksiyanı çağırıb gələn dəyəri konsolda göstərin.

**Tapşırıq 11:** `kvadratHesabla` adlı funksiya yazın. Bir ədəd qəbul etsin və onun kvadratını hesablasın

**Tapşırıq 12:** Bir funksiya daxilində `return` sözündən sonra konsola yazı yazmağa çalışın (`console.log("Test")`).

**Tapşırıq 13:** Eyni funksiya daxilində şərtə bağlı (`if/else`) istifadə edərək kod yazın

**Tapşırıq 14:** Həm konsola yazı yazdıran (void), həm də `return` edən bir funksiya yazın. Bu funksiyanın daxilindəki `console.log` ilə `return` arasındakı fərqi izah edin.

**Tapşırıq 15:** Arrow function ilə funksiya yaradın

**Tapşırıq 16:** `endirimHesabla` adlı bir funksiya yaradın.

* Bu funksiya iki parametr qəbul etməlidir: `qiymet` və `endirim`.
* `endirim` üçün defolt dəyər `10` (yəni 10%) təyin olunmalıdır.
* Funksiya daxilində yeni endirimli qiymət hesablanmalı və `return` edilməlidir.
* Bu funksiyanı **Arrow function** olaraq yazın.

**Tapşırıq 17:** `boyukOlaniTap` adlı funksiya yazın. İki ədəd qəbul etsin və onlardan böyük olanını tapıb `return` etsin.

**Tapşırıq 18:** `temperaturCevir` adlı funksiya yaradın. Selsi (Celsius) dəyərini parametr kimi götürüb, onu Farenheytə (Fahrenheit) çevirsin və qaytarsın.

Formula: **$F = C \times 1.8 + 32$**

**Tapşırıq 19:** Bir funksiya yazın, parametr olaraq doğulduğu ili qəbul etsin və istifadəçinin yaşını hesablayıb geri qaytarsın.

**Tapşırıq 20:** `faizHesabla` funksiyası qurun. Ədəd və faiz dərəcəsi qəbul etsin. Ədədin həmin faizini hesablayıb qaytarsın.

**Tapşırıq 21:** `menfiMusbet` funksiyası yazın. Ədəd sıfırdan böyükdürsə `"Müsbət"`, kiçikdirsə `"Mənfi"`, sıfıra bərabərdirsə `"Sıfır"` sözünü göstərsin

**Tapşırıq 22:** `kalkulyator` funksiyası yaradın. Üç parametr qəbul etsin: `a`, `b` və `operator` (`"+"`, `"-"`, `*`, `"/"`). Operatora əsasən uyğun riyazi əməliyyatın nəticəsini qaytarsın.

**Tapşırıq 23:** `girişYoxla` funksiyası qurun. Parametr olaraq `istifadeciAdi` və `shifre` qəbul etsin. Əgər istifadəçi adı `"admin"` və şifrə `"12345"` olarsa `"Giriş uğurludur"`, əks halda `"Məlumatlar yanlışdır"` mesajını qaytarsın.

**Tapşırıq 24:** `tekYoxsaCut` adlı bir arrow funksiyası yazın. Əgər ötürülən ədəd cütdürsə `true`, təkdirsə `false` qaytarsın (Məsləhət: `%` operatorundan istifadə edin).

**Tapşırıq 25:** Bir tələbənin imtahan balına uyğun A, B, C, D, F qaytaran funksiya yazın.

**Tapşırıq 26:** `sadeEded` funksiyası yaradın. Ötürülən ədədin sadə (həm 1-ə, həm də özünə bölünən) olub-olmadığını yoxlasın (`true`/`false`).

**Tapşırıq 27:** `kmToMiles` funksiyası yazın. Kilometri mil-ə çevirsin (1 km ≈ 0.621371 mil). Defolt olaraq parametrə 0 dəyəri verilsin.

**Tapşırıq 28:** `mesajFormatla` adlı funksiya yazın. İki parametr qəbul etsin: `ad` və `gun`. Məsələn: `mesajFormatla("Əli", "Bazar ertəsi")` çağırıldıqda geriyə `"Salam Əli, bu gün Bazar ertəsi günüdür."` cümləsini qaytarsın (Template literals `backtick` istifadə edin).

**Tapşırıq 29:** Aşağıdakı kodda nə üçün xəta (`ReferenceError`) baş verdiyini izah edin və kodu elə düzəldin ki, funksiya düzgün işləsin:

**JavaScript**

```
function hesabla() {
    let netice = 50 * 2;
}
hesabla();
console.log(netice); 
```

**Tapşırıq 30:** Aşağıdakı arrow funksiyasında xətanı tapın və düzəldin:

**JavaScript**

```
const salamDe = ad => { return "Salam " + ad };
```
