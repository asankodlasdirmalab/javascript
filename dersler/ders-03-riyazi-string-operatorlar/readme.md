Mövzular

*  Arithmetic (Riyazi) Operatorlar :
* + (toplama rəqəmlər üçün)
* - (çıxma)
* * (vurma)
* / (bölmə)
* % (bölmədən qalan qalıq)
* ** (qüvvətə yüksəltmə)
* ++ (bir bir artırma)
* -- (bir bir azaltma)

#### Assignment (Dəyər təyinetmə) Operatorlar :

* = (təyin etmə)
* += (toplayaraq yaxud birləşdirərək təyinetmə)
* -= (çıxaraq təyinetmə)
* *= (vuraraq təyinetmə)
* /= (bölərək təyinetmə)
* %= (qalıqlı təyinetmə)

#### String (Mətn)  Operatorları:

* + (concatenation - string birləşdirmə)
* Tick ilə birləşdirmə: `Hello ${name}`
