# [JavaScript Dərs 6 Arrays](https://docs.google.com/presentation/d/14B03tat9k1rBeDtHHPFmV9nV7fBrHnuLAIJEI3O62-4/edit?slide=id.p#slide=id.p)

Mövzular

* Array yaratmaq: `[1,2,3],  new Array()`
* Arraydan element götürmək (indexlər)
* Array-da element sayı: `arr.length`
* Sonuncu elementi qaytarmaq: `arr[arr.length - 1]`
* Negative indexing: `arr.at(-1)`
* Nested arrays: `[[1, 2],[3, 4]]`
* Nested array-dən element qaytarmaq: `arr[1][2]`
* Array destructuring: `const [a, b, c] = arr`
