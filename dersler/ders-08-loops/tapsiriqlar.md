# **Dərs 8: JavaScript Loops - Tapşırıqlar**

### Tapşırıq 1

 `for` dövründən istifadə edərək bu məhsulların ümumi məbləğini hesablayın və göstərin.

```javascript
const sebet = [15.5, 45.0, 9.99, 120.0, 32.5];
```

### Tapşırıq 2

`for...of` dövründən istifadə edərək hər bir email  mesaj göndərin `"Bildiriş göndərildi: [email]"` formatında yazı çıxarın.

```
const epoctlar = ["kamil@gmail.com", "leyla@mail.ru", "orxan@code.edu.az"];
```

#### Tapşırıq 3

```
let batareya = 100;
```

### Tapşırıq 4

temperaturları yoxlayın  **40 dərəcəni keçərsə** , loop dayansın və ekrana `"Yüksək temperatur!"` yazılsın.
